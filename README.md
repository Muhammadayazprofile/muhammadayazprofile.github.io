# Muhammad Ayaz — Personal Portfolio

A responsive personal portfolio inspired by the Agel/Agencie black-and-orange agency template aesthetic. This is an original portfolio implementation, not a copy of the Framer source/template.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Wait for deployment, then open `https://YOUR-USERNAME.github.io/`.

## Customize before publishing
- Replace `assets/muhammad-ayaz.webp` if you want to use a different portrait.
- Review the email and LinkedIn links in `index.html`.
- The selected-work cards describe areas of expertise, not named client case studies or verified performance claims. Replace them with actual project links/images when ready.
- The `12+` experience figure is based on the career timeline beginning in 2014.

No paid hosting or domain is required for the GitHub Pages URL.
